# Jarloom Studio

A static website for a product-promotion design service.

Open index.html locally, or host the repository root with GitHub Pages. The site includes a responsive sample gallery, package descriptions, FAQs, and an enquiry form that opens an email draft addressed to y3m12005@gmail.com. It does not automatically send messages or collect payments.

Morrow Wick is a fictional portfolio example with AI-generated product images. Checkout remains inactive until payment setup is verified.
